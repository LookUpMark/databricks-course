# Task wrappers

**Optional placeholder.** The current course and its bundle use no files from this directory. It illustrates a place to keep future Lakeflow job entry points that delegate work to a shared Python package.

If you add a task, define its entry point and parameters in the corresponding job YAML under [resources/](../resources/README.md). Keep the business logic in a testable package and include any new runtime directory in the bundle's sync paths. For the working example, see [topic 09](../course/09-lakeflow-jobs/LESSON.md).
